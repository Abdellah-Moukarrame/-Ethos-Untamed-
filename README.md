# Ethos Untamed
This repository contains the source code for the promotional website of "Ethos Untamed," a sci-fi action game by Heykaya Interactive. The website features a futuristic design and guides users through an interactive, multi-step profile creation process for the game.

## Features

*   **Main Landing Page**: A visually rich hero section introducing the game's slogan, "the fight has just begun."
*   **Interactive Profile Creation**: A step-by-step process that allows users to set up their in-game persona:
    1.  **Avatar Selection**: Choose a character and username.
    2.  **Companion Selection**: Select a free companion, such as a Turtle, Rhino, or Dino.
    3.  **Weapon Assignment**: View the starting weapon, like the Assault Rifle.
    4.  **Friend Referral**: An interface to invite friends and unlock epic rewards.
    5.  **Confirmation**: A final screen confirming the character setup.
*   **Story Introduction**: A dedicated section that delves into the game's lore, set in the year CE 4301.
*   **Custom Styling**: A unique, futuristic aesthetic built with custom CSS and fonts like Orbitron and Blender Pro.
*   **Newsletter Signup**: A section prompting users to sign up for the game's newsletter.

## Website Flow

The user journey is designed as a linear progression through the character setup process:

1.  **`index.html`**: The main entry point. It presents the game's story and leads the user to start creating a profile.
2.  **`devblog.html`**: The first step in profile creation, where the user selects a companion.
3.  **`weapon.html`**: The next step, which displays the default weapon the player will receive.
4.  **`Friends.html`**: A social sharing page that encourages users to invite friends in exchange for in-game rewards.
5.  **`carachter.html`**: The final confirmation page that showcases the chosen character and leads to starting the game.

## Technologies Used

*   **HTML5**: Structures the content of all web pages.
*   **CSS3**: Provides the custom styling, layout, and futuristic design.
*   **Fonts**:
    *   Orbitron
    *   Blender Pro

## Setup and Usage

To run this website locally, follow these steps:

1.  Clone the repository to your local machine:
    ```bash
    git clone https://github.com/abdellah-moukarrame/-ethos-untamed-.git
    ```
2.  Navigate into the cloned directory:
    ```bash
    cd -ethos-untamed-
    ```
3.  Open the `index.html` file in your web browser to view the website.
